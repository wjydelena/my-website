# Font sources

TikTok Text Regular, Medium and Bold are embedded for this prototype. Internal font family metadata was verified before use; these are not aliases for TikTok Sans.

Source: https://www.globalfonts.pro/font/tiktok

Files originate from that page's `TikTokText-Regular.woff`, `TikTokText-Medium.woff2` and `TikTokText-Bold.woff2` links. Regular was losslessly converted from WOFF to WOFF2 with FontTools. The source site labels this as a paid typeface; confirm the appropriate font license before external production distribution. The prototype does not grant a separate font license.

## User-supplied Pin countdown font (v1.71)
`TikTokSans12pt-Bold.woff2` is converted losslessly from `ttf/TikTokSans12pt-Bold.ttf` inside the user's uploaded `ttf.zip`. It retains the supplied small-optical-size outlines and actual Bold (700) weight. The dedicated `TikTok Sans 12pt` CSS family is used only for Group Deal and Price Cut thumbnail timers, at 13 CSS px. Other UI font assignments are unchanged.
